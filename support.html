WARDEN'S HELP DESK

Find the path back

Start with the safe checks below. The help desk does not ask for passwords, cookies, account secrets, security tokens, or private API responses.

Installing the Android APK

Use the direct APK from the Download page. Android 8.0 or newer is required. Allow installs only for the browser or file manager you used, then revoke that permission if you prefer.

Verifying the checksum

Download the companion SHA-256 file and run sha256sum -c akalynth-beta-v12.apk.sha256 beside the APK.

Account or character trouble

Return to Characters & Account. Expired sessions require a new sign-in. A character must belong to the signed-in account before it can be selected.

Housing or shop rejection

The server may reject insufficient gold, stale listings, an already-sold property, ownership mismatches, or an expired security token. Refresh and retry only after reading the exact message; ambiguous mutations are never retried automatically.

Connection troubleshooting

Confirm ordinary internet access, reopen Akalynth, select the Prod preset, and check that the app says Online. Never start a second local game server to work around a public connection problem.

Community conduct

Keep High City welcoming. Do not share credentials, exploit details, private receipts, harassment, or personally identifying information in community spaces.
